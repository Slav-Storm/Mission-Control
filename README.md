# Mission Control

A Minecraft challenge in Monifactory expert mode: ten specialised programmable
robots explore, mine and transport resources for a player who stays at Mission
Control. Initial bootstrap is permanently sealed.

This public repository contains concise progress reports for completed Minecraft
days. Recording started partway through day 4; earlier daily history is not
invented. Detailed positions, robot telemetry, routes, logs and source stay local.

An in-game recorder detects actual day changes. A local Codex automation checks
for completed reports every five minutes and uploads each day once. The computer,
Codex and authenticated GitHub browser session must remain available. Minecraft
must run for in-game days to advance.

Current stage: exploration and primitive resource collection. Crafting, storage
and industrial production remain unfinished.
